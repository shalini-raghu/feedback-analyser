# Feedback Analyser

A small Python project that analyzes customer feedback using FastAPI and Gemini.

## What it does

- Accepts customer reviews through a FastAPI backend
- Sends each review to a Gemini model for sentiment analysis
- Returns:
  - `label`: `positive`, `negative`, or `neutral`
  - `score`: 1 to 5
  - `theme`: the main topic of the review
- Stores review results in a local SQLite database
- Displays results in a Streamlit dashboard

## Project structure

- `api.py` — FastAPI backend
- `app.py` — Streamlit frontend
- `database.py` — SQLite database helpers
- `sample_reviews.txt` — example reviews to test with
- `feedback.db` — local database file generated by the app
- `.env.example` — template for environment variables
- `.gitignore` — excludes local secrets and generated files

## Setup

1. Create a virtual environment and install dependencies:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

If you are using `uv`:

```bash
uv sync
```

2. Create a local environment file:

```bash
cp .env.example .env
```

3. Add your Gemini API key to `.env`:

```env
GEMINI_API_KEY=your_api_key_here
```

Important: keep `.env` local and do not commit it.

## Run the app

Start the backend in one terminal:

```bash
uv run fastapi dev api.py
```

Start the frontend in another terminal:

```bash
uv run streamlit run app.py
```

## Example usage

The backend endpoint is:

```http
POST /analyze
```

Example JSON body:

```json
{
  "text": "The delivery was fast and the product quality was excellent."
}
```

Example response:

```json
{
  "label": "positive",
  "score": 5,
  "theme": "delivery"
}
```

## Security notes

- Never commit real API keys or secrets.
- Keep environment secrets in `.env` and ignore it with Git.
- Commit only `.env.example` as a template.
